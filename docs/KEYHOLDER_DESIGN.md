# わけたま NFCキーホルダー 設計仕様

50mm × 50mm / 削り出し対応
最終更新: 2026-09-19

図面と加工データ: [keyholder/](keyholder/)（`tools/keyholder/make_keyholder.py` が生成）

| ファイル | 中身 |
|---|---|
| `keyholder_front.svg` | 表面。外形・勾玉・キーリング穴、寸法つき |
| `keyholder_back.svg` | 裏面。インレイの座ぐりと蓋の段差 |
| `keyholder.dxf` | 加工用。外形・穴・座ぐり・彫り込みを層で分けてある |

## 0. 先に読むべきこと ― 金属はNFCを止める

**これが設計上の最大の論点。** アルミや真鍮の塊にNFCインレイを埋めると、
渦電流でアンテナの磁束が食われて**読めなくなる**。「削り出しで作りたい」と
「NFCで動かしたい」は、素のままでは両立しない。

対処は2つ。どちらを取るかで材料が決まる。

| 案 | 材料 | NFCの扱い | 向き |
|---|---|---|---|
| **A: 樹脂・木で削り出す** | POM（ジュラコン）、アクリル、ウォルナット | 何も要らない。素直に読める | 量産・確実性を取る |
| **B: 金属で削り出す** | 真鍮 C3604、アルミ A5052 | 座ぐりの底に**フェライトシート**（0.1〜0.3mm）を敷く | 質感・重さを取る |

**推奨はB（真鍮）＋フェライト。** キーホルダーは手に取ったときの重さが体験そのもので、
樹脂だとおもちゃに見える。フェライトシートは1枚十数円で、metal-mount用NFCタグでは標準の手法。

> ⚠ Bを選ぶなら、**試作の段階で必ず実機のスマホで読む**こと。
> フェライトの厚み・インレイの種類・スマホの機種で読み取り距離が変わる。
> 設計が正しくても、0.1mm薄いだけで読めないことがある。

## 1. 外形

| 項目 | 値 | 理由 |
|---|---|---|
| 外形 | 50 × 50 mm | 指定寸法。カードキーと同程度で、鞄の中で見失わない |
| 板厚 | 4.0 mm | インレイ(0.9)＋蓋(0.6)を引いても表側に2.5mm残る。曲げに耐える |
| 角R | R6 | 握ったとき角が当たらない最小限。R4だと痛い |
| キーリング穴 | ø4.0 貫通、中心 (6, 6) | 縁の残り4mm。真鍮なら十分もつ |
| 質量（真鍮の場合） | 約 78 g | 50×50×4 × 8.5 g/cm³ − 座ぐり分 |
| 質量（POMの場合） | 約 14 g | |

## 2. 表面（意匠）

- 勾玉を**高さ34mm**で中央に配置。周囲に8mmずつ残る
- 彫り込み **深さ0.8mm**（ポケット加工）
- 頭の穴（ø約9.4mm）は**貫通させない**。同じ0.8mmの彫り込み
- 仕上げ: 彫り込みの底だけ梨地、平面はヘアライン。色を入れるなら彫り込みへ塗料充填（#7c5cff）

> 勾玉の輪郭には内側のくびれがある。**刃物はø3以下**を使うこと。
> ø4だと尾の先が丸まって、別の形になる。

## 3. 裏面（NFCインレイ）

| 項目 | 値 |
|---|---|
| インレイ | 丸形 ø25mm（NTAG213 / NTAG215）、厚み 0.20〜0.25mm |
| 座ぐり | ø26.0 × 深さ0.9（インレイ＋フェライト＋余裕） |
| 蓋の段差 | ø28.0 × 深さ0.6 |
| 蓋 | ø27.8 × 厚み0.6 の円板（同材 or アクリル）。接着 |
| フェライト（金属材のみ） | ø25 × 0.2mm を座ぐりの底に貼る |

**積み上げ**: 座ぐり底 → フェライト0.2 → インレイ0.25 → 余裕0.45 → 蓋0.6 → 裏面。

蓋の代わりにエポキシ充填でもよい。その場合は段差0.6を充填の深さとして扱う。
**充填のほうが防水は強いが、インレイが死んだときに交換できない。**
試作のうちは蓋（接着を弱め）にしておくと、読めなかったときに作り直さずに済む。

## 4. 加工（削り出し）

材料: 50×50×5mm の板材から（仕上げ代1mm）

| 工程 | 刃物 | 内容 |
|---|---|---|
| 1 | ø6 エンドミル | 外形の粗取り（タブ残し） |
| 2 | ø3 エンドミル | 外形の仕上げ、角R6 |
| 3 | ø3 エンドミル | 表面の勾玉ポケット 深さ0.8 |
| 4 | ø4 ドリル | キーリング穴 貫通 |
| 5 | ø6 エンドミル | 裏返して 座ぐり ø26×0.9、段差 ø28×0.6 |
| 6 | — | バリ取り、面取りC0.3 |

- **最小内R = 1.5mm**（ø3の刃物の半径）。図面の内Rはすべてこれ以上にしてある
- 平面度 0.1、板厚公差 ±0.1
- 座ぐりの深さ公差は **+0.1 / −0**。浅いとインレイが浮いて蓋が閉まらない

## 5. 書き込む内容

タグに書き込むのは1件のURLレコード（NDEF）だけ。

```
https://app.waketama.com/t/<コード>
```

- コードは管理画面「依代（タグ・QR）」で発行したもの（`/api/admin/tags`）
- **1枚1コード。** 同じコードを2枚に書くと、後から読んだ人は他人の分身に着く
- 書き込み後は**読み取り専用にロックする**（NTAGの静的ロックビット）。
  ロックしないと、拾った人が別のURLへ書き換えられる
- 書き込んだら**必ず1枚、実機で読む**。配ってからでは直せない

## 6. 試作のチェックリスト

- [ ] 外形 50±0.2、板厚 4±0.1
- [ ] キーリングが通る（ø4の穴に、線径2.5mmのリングが通ること）
- [ ] 勾玉の尾の先が潰れていない（ø3以下の刃物を使ったか）
- [ ] 蓋が段差に収まり、裏面から出っ張らない
- [ ] **iPhone と Android の両方で読める**（機種でアンテナ位置が違う。上端・中央の両方で試す）
- [ ] 読み取り距離が5mm以上（ケース越しでも読める余裕）
- [ ] 落下（1.2m、コンクリート）で蓋が外れない
- [ ] URLがロックされていて、書き換えられない

## 7. 目安の原価（100個、日本国内）

| 項目 | 単価 | 備考 |
|---|---|---|
| 真鍮の削り出し | 800〜1,500円 | 数量で大きく動く。500個で半分程度 |
| POMの削り出し | 300〜600円 | |
| NFCインレイ（NTAG213 ø25） | 30〜60円 | |
| フェライトシート | 10〜20円 | 金属材のみ |
| 蓋・接着 | 20〜50円 | |
| 書き込み・検品 | 50円 | 1枚ずつ読んで確認する手間 |

真鍮なら1個あたり1,000〜1,700円。**量産するなら、削り出しではなく鋳造＋研磨**のほうが安い。
削り出しは、少量の試作・受注生産・「削り出し」という文言自体を売りにする場合に向く。

## 8. 変更するとき

寸法は `tools/keyholder/make_keyholder.py` の冒頭の定数がすべて。
そこを直して再実行すれば、図面もDXFも一緒に変わる。

```bash
python3 tools/keyholder/make_keyholder.py
```

**図面だけを手で直さないこと。** ロゴを直したときに現物だけ古い形で残る。
